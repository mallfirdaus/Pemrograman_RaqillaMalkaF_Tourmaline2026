# Pemrograman_RaqillaMalkaF_Tourmaline_TLS26

## Identitas

**Nama:** Raqilla Malka Firdaus
**Kelompok:** Tourmaline

## Deskripsi

Repository ini berisi hasil pengerjaan tugas Pemrograman TLS 26 yang terdiri dari Fase 1 dan Fase 2.

### Fase 1

Fase 1 berisi logika penyelesaian dua problem dalam bentuk pseudocode dan flowchart serta penjelasan mengenai logika penyelesaian masing-masing problem.

Problem yang dikerjakan:

* The Last Astronaut
* Alien-In-The-Middle

Hasil pengerjaan Fase 1 terdapat dalam file PDF.

### Fase 2

Fase 2 berisi implementasi solusi dari kedua problem menggunakan bahasa pemrograman C++.

File yang terdapat dalam repository:

* `problem1.cpp` — program The Last Astronaut
* `problem2.cpp` — program Alien-In-The-Middle

Program dibuat dengan menggunakan library `iostream` sesuai dengan ketentuan tugas.
